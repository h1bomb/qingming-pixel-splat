清明上河图 · 虹桥夜渡

Pixel-Art Gaussian Splatting 复现：SDF 表面采样 → 高斯泼溅 → 低分辨率色板 Resolve。拖动可环视，船会自动收帆过桥。
扬帆顺流

管线说明：场景不用三角面片建模，全部形状由解析曲面（盒、椭球、圆柱、拱环、平面）做表面采样生成高斯点（约 1.2 万个）， 每帧按深度排序投影成椭圆泼溅，再在 480×270 逻辑分辨率上做色板量化 + 抖动 + 最近邻放大。 关掉「像素化 Resolve」可以看到泼溅原始的柔和样子——像素味来自最后这一层，不是原图滤镜。 同一场景的 Ink Studio 原生版本在 scenes/qingming-night.js，可用上游 CLI 渲染成 PNG。
